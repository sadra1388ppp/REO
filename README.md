# Reo

A clean, minimal stopwatch for Windows, built with Python and Tkinter.

## Features

- Pure black interface
- Neon green digits while running
- Red digits while stopped or paused
- Four decimal places: `0.0000`
- Start, pause, resume, and reset controls
- Keyboard shortcuts: **Space** to start/pause, **R** to reset
- No third-party packages required

## Run

Install Python 3.10 or newer, then run:

```powershell
python main.py
```

Tkinter is included with most standard Windows Python installations.

## Clone

```powershell
git clone https://github.com/sadra1388ppp/Timmer.git
cd Timmer
python main.py
```
